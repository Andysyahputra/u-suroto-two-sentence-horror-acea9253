Entry for the [Two-Sentence Horror](https://make.fun/competitions/u-suroto-two-sentence-horror-acea9253) competition on [make.fun](https://make.fun).

## What it does

`main.py` writes one original two-sentence horror story to `/output/entry.txt`.
It is deterministic — no randomness, no network, no input — so every run
produces the same text.

## The story

A child tapes a new drawing to the fridge every night: the same tall man
at the end of the driveway, a little closer each time. One morning there
is no drawing — only a single muddy footprint on the kitchen floor, and
her crayons still sealed in the box. The horror is implied, never
explained: the drawings have stopped because what she was drawing is
already inside.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
